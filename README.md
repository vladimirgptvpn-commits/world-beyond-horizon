# Мир за горизонтом / World Beyond Horizon

Открытый прототип текстового фэнтези-приключения для ChatGPT. Игрок свободно описывает действия; ведущий поддерживает непротиворечивое состояние мира и последствия решений.

## Статус

**v0.2 — первое играбельное локальное демо в рабочей ветке; это ещё не опубликованный плагин ChatGPT.** Интеграция Google Drive, перенос сохранений между чатами и упаковка плагина требуют отдельного испытания.

## Принципы

- Мир развивается в игровом времени при действиях и пропусках времени, но не во время отсутствия игрока.
- География и события генерируются по мере необходимости с сохранением причинности.
- Игрок свободен в действиях и мотивации; ИИ не назначает ему убеждения или поступки.
- Начальное создание героя — максимум пять вопросов.
- Сохранение выполняется **только по явной команде** и подтверждается после фактической записи и проверки.
- Личные миры каждого игрока должны храниться отдельно в его Google Drive; GitHub не требуется игроку.
- Графические редакторы, MagicPath и собственный сервер не входят в v1.

## Содержимое

- `plugin/skills/character-creation/SKILL.md` — проект первого игрового навыка.
- `plugin/references/world-rules.md` — неизменяемые принципы мира.
- `schemas/` — JSON Schema для героя, мира и сохранения.
- `examples/starter-world/` — пример минимального мира.
- `tests/` — проверки базовых инвариантов.

## План испытаний

1. Проверить создание героя и непротиворечивое применение пяти ответов.
2. Проверить сохранение и восстановление состояния из файлов без Google Drive.
3. Проверить доступность Google Drive в контексте устанавливаемого навыка/плагина.
4. Проверить реальную запись, чтение и перенос между чатами.
5. Только после успешных испытаний выбирать способ публикации.

Лицензия и способ публичной публикации пока не утверждены.

## Играбельное демо v0.2

Для запуска понадобится Node.js 22+ (без дополнительных библиотек):

```bash
node engine/play.mjs
```

После пяти ответов о герое введите `помощь`. Можно исследовать четыре места, разговаривать с двумя NPC, брать и возвращать фонарь, изучать карту и ждать. Только явная команда `сохранить игру` пишет локальный файл; восстановление из Google Drive будет отдельным этапом.

Подробности: [инструкция по запуску](engine/README.md), [первый пример](examples/first-adventure.md), [поведенческий навык](plugin/skills/adventure-runtime/SKILL.md).

Тесты: `node --test tests/game-engine.test.mjs`. Эта реализация — маленькая контрольная игровая сцена, а не открытый генератор неограниченного мира.
